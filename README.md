# SmartStreamTV

**SmartStreamTV** is a fork of [SmartTwitchTV](https://github.com/fgl27/SmartTwitchTV) — an Android TV client for Twitch — with additional features:

- **ReYohoho proxy** — unlocks 1080p/1440p (2K) quality on streams via the [reyohoho/twitch_quality_proxy](https://github.com/reyohoho/twitch_quality_proxy) backend, with automatic server rotation and an optional ad free token mode
- **Chat performance** — batched message rendering, compositor friendly animations and emote image limits (per message and for the whole chat) for smooth chat on low end TV devices
- **WIP: Multi platform support** — Kick, VK Video Live, W.TV and more (in progress)

All documentation for building, translating and testing (unchanged from upstream) is available in the [original repository](https://github.com/fgl27/SmartTwitchTV).
